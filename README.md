# 🏙️ Local Community Event Portal

A full-stack learning project built with HTML, CSS, JavaScript, SQL, and Java.

## 🌐 Live Project
> Open `index.html` in your browser to run the portal locally.

## 📁 Project Structure

```
Local Community Event Portal/
├── index.html          # Main portal page
├── help.html           # Help & FAQ page
├── main.js             # JavaScript logic
├── styles.css          # Custom styles
└── exercises/
    ├── 20-sql/         # Module 2 — SQL Exercises
    │   └── module2_exercises.sql
    └── 21-java/        # Module 3 — Core Java Exercises
        ├── Ex01_HelloWorld.java
        ├── Ex02_SimpleCalculator.java
        └── ... (41 exercises total)
```

## 🧩 Modules

### Module 1 — Frontend (HTML, CSS, Bootstrap, JavaScript)
- Responsive layout with Bootstrap 5
- Event listing, registration form, gallery
- jQuery demo, geolocation, localStorage
- Fetch API, async/await

### Module 2 — ANSI SQL Using MySQL
- 6 table schema: Users, Events, Sessions, Registrations, Feedback, Resources
- 25 SQL exercises covering JOINs, subqueries, aggregations, date functions

### Module 3 — Core Java
- 41 exercises covering:
  - Basics, OOP, Collections, File I/O
  - Multithreading, Lambda, Streams, Records
  - JDBC, Sockets, HTTP Client, Reflection
  - Virtual Threads (Java 21), Pattern Matching (Java 21)

## 🚀 How to Run

### Frontend
1. Open `index.html` in any browser

### SQL Exercises
1. Install MySQL + MySQL Workbench
2. Open `exercises/20-sql/module2_exercises.sql`
3. Run schema, then sample data, then exercises

### Java Exercises
1. Install JDK 21 from https://adoptium.net/
2. Open `exercises/21-java/` in VS Code or IntelliJ
3. Compile and run any file:
```bash
javac Ex01_HelloWorld.java
java Ex01_HelloWorld
```
