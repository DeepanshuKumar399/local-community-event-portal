Bootstrap Directory Structure

  • css/ – Contains bootstrap.css, bootstrap.min.css, and RTL variants. These provide all utility classes, grid, and component styles.
  • js/ – Contains bootstrap.js, bootstrap.min.js, and bootstrap.bundle.min.js (includes Popper.js). Powers interactive components like modals, dropdowns, and tooltips.
  • icons/ – (Bootstrap Icons package) Contains SVG icon files and an icon font. Used to add scalable vector icons to UI elements.
